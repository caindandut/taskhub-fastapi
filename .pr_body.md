## Phạm vi thay đổi (Scope)
- **Database & Engine Configuration**:
  - Cấu hình SQLAlchemy 2.x async engine với MySQL (`mysql+aiomysql`) và SQLite (`sqlite+aiosqlite`) phục vụ testing.
  - Quản lý vòng đời engine và session factory (`async_sessionmaker`) trong FastAPI `lifespan`.
  - Cung cấp hàm `get_settings()` có `@lru_cache` để tối ưu đọc cấu hình môi trường.
- **Models & Migrations**:
  - Định nghĩa đầy đủ các model: `User`, `Workspace`, `WorkspaceMember`, `Project`, `Task`, `Label`, `Comment`.
  - Sử dụng SQLAlchemy 2.0 `Mapped` và `mapped_column`, quan hệ `relationship` với cascading/foreign keys đúng chuẩn.
  - Sử dụng hằng số `TASK_TITLE_MAX_LENGTH` cho độ dài tiêu đề task trong model `Task`.
  - Cấu hình Alembic async migrations (`alembic/`) và tạo migration ban đầu.
- **Repository, Service & Endpoints**:
  - Generic `BaseRepository` và `TaskRepository` bất đồng bộ xử lý truy vấn, lọc dữ liệu và phân trang.
  - `TaskService` xử lý logic nghiệp vụ và kiểm tra ràng buộc khóa ngoại (creator, project, assignee).
  - Tách `BaseSchema` chung trong Pydantic schemas, `TaskRead` không kế thừa từ `TaskCreate`.
  - Serialize `created_at` và `due_date` kèm timezone UTC (`Z`).
  - Đưa message `This field cannot be null` vào file `app/core/messages.py`.
  - Tạo base `AppException` và đăng ký global exception handler cho `AppException` và `IntegrityError`.
  - Chuẩn hóa return type endpoint task trả về `TaskRead` thông qua `TaskRead.model_validate(task)`.
  - Loại bỏ việc mount router `health` trùng lặp (chỉ mount qua `api_router` tại `/api/v1/health`).
- **Gitignore & Clean up**:
  - Khôi phục đầy đủ template `.gitignore` gốc (Python, venv, pytest, ruff, coverage, IDEs).

## Cách chạy Migration
```bash
# Thiết lập biến môi trường DATABASE_URL trong .env hoặc terminal:
# DATABASE_URL=mysql+aiomysql://root:password@localhost:3306/taskhub
# hoặc dùng SQLite cho development:
# DATABASE_URL=sqlite+aiosqlite:///taskhub.db

# Chạy migration lên phiên bản mới nhất:
alembic upgrade head

# Rollback migration (nếu cần):
alembic downgrade base
```

## Cách chạy Test
```bash
# Chạy toàn bộ test suite:
pytest

# Hoặc chạy test với temp dir tuỳ chỉnh (trên Windows):
pytest --basetemp=.tmp/pytest -p no:cacheprovider
```
